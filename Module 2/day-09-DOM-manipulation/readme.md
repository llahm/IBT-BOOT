# Addis Market Shopping List

An interactive shopping list application built with HTML, CSS, and vanilla JavaScript.

## Features

- Add an item with its name and ETB price
- Validate item name and price
- Prevent the form from reloading the page
- Dynamically create items using `createElement()`
- Add elements using `append()`
- Delete items using event delegation
- Mark items as bought by clicking on them
- Toggle a CSS `bought` class
- Display a live running total in ETB
- Update the total when items are added
- Update the total when items are deleted

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No installation is required.
